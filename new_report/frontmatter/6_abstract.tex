\section*{Abstract}
\addcontentsline{toc}{section}{Abstract}
\label{sec::abstract}

Printymand is a web platform designed for print-on-demand commerce. It connects customers, independent designers, printers, and administrators within a unified marketplace workflow. Customers can browse designs, customize products, choose a printer, place orders, and track their fulfillment. Designers can publish artworks, manage product compatibility, and monitor commercial indicators. Printers can manage printable products and update production progress. Administrators can supervise users, content, and global platform activity.

The platform was implemented with Angular and TypeScript for the single-page front-end application, NestJS for the REST back-end API, and PostgreSQL for relational data persistence. The system integrates JWT authentication, role-based authorization, validation, modular services, reusable user interface components, and a structured database model. The adopted methodology is the Spiral Model, which allowed us to develop the project progressively while controlling risks related to security, order integrity, user roles, and marketplace coordination.

This report presents the context, comparative study, requirements, architecture, implementation cycles, and evaluation of Printymand. It shows how the platform answers local print-on-demand needs through a complete academic software engineering project.
