\chapter*{General Conclusion}
\addcontentsline{toc}{chapter}{General Conclusion}

This PFA project allowed us to design and implement Printymand, a print-on-demand marketplace platform that connects customers, designers, printers, and administrators.
Through this work, we addressed a realistic software engineering problem involving multi-role workflows, product customization, order management, authentication, authorization, database modeling, and full-stack architecture.

On the front-end side, we developed an Angular application that provides marketplace browsing, authentication, role-specific dashboards, product customization, printer selection, cart management, checkout, order tracking, reviews, and profile management.
On the back-end side, we implemented a NestJS API with authentication, authorization, persistence, validation, exception handling, monitoring, and modular business services.
PostgreSQL was used to model the main entities of the marketplace and preserve the relationships between users, products, designs, printers, and orders.

The Spiral Model helped us organize the project progressively.
The first cycle established authentication, onboarding, and marketplace discovery.
The second cycle implemented customization, cart, checkout, and order tracking.
The third cycle completed the platform with dashboards, administration, governance, monitoring, and technical optimization.

This project was a valuable academic and technical experience.
It strengthened our skills in Angular, NestJS, PostgreSQL, TypeScript, software architecture, and project organization.
It also showed the importance of communication between front-end and back-end development when building a coherent platform.

As perspectives, Printymand can be enhanced with advanced recommendation algorithms, additional online payment providers, automated invoice generation, real-time notifications, multilingual deployment, and production cloud hosting.
These improvements would extend the platform and prepare it for broader market usage.

In conclusion, Printymand demonstrates how a local print-on-demand marketplace can be designed and implemented with modern web technologies while answering the needs of customers, designers, printers, and administrators.
